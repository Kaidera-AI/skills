# Web Reader

A tiny capability for reading the contents of a public website from a shell.

## How to use

Given a URL, fetch and print its readable text:

```bash
# Fetch raw HTML/text of a page
curl -fsSL "https://example.com" | head -c 4000
```

To strip tags to rough plain text (best effort):

```bash
curl -fsSL "$URL" \
  | python3 -c 'import sys,re; t=sys.stdin.read(); t=re.sub(r"<script.*?</script>","",t,flags=re.S|re.I); t=re.sub(r"<[^>]+>"," ",t); print(re.sub(r"\s+"," ",t).strip()[:4000])'
```

Always prefer `curl -fsSL` (fail on error, silent, show errors, follow redirects).
